## Why there is no ORC notice on this

Paizo's rules text is under the Open RPG Creative License, and using the ORC requires including an
attribution block for the material you took from it. This project quotes no ORC-licensed text: no
rule paragraph, no spell description, no stat block, no feat entry. It uses bare functional numbers and
short titles, and adds its own mechanics.

That is also why the project deliberately does **not** carry an ORC notice. Adopting the ORC makes
every mechanic in your own document Licensed Material that must be handed downstream, which is a fine
choice but a real one, and it is not compatible with putting the prose under a noncommercial license.
If a future version of these docs starts quoting actual PF2e text, the ORC notice and its attribution
go in and this section gets rewritten.
